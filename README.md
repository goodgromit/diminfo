# diminfo

World of Warcraft **Forever**용 정보 바 애드온입니다. 화면 위쪽의 얇은 바에 메모리, FPS, 지연 시간, 친구, 길드, 소지금, 내구도, 가방, 지역 정보를 보여 줍니다.

- 지원 버전: WoW Forever 1.60.1 (Interface 16001)
- 지원 언어: 한국어, 영어, 중국어(번체, 간체)

## 설치

`diminfo` 폴더를 `World of Warcraft\_forever_\Interface\AddOns\` 아래에 넣고 게임을 시작합니다.

## 항목별 기능

바에 마우스를 올리면 툴팁이 뜨고, 왼쪽 클릭과 오른쪽 클릭으로 기능을 쓸 수 있습니다. 대부분의 툴팁은 **Shift**를 누르면 더 많은 정보를 보여 줍니다.

### 메모리

| 구분 | 내용 |
|---|---|
| 바 | 로드된 애드온의 메모리 사용량 합계 (예: `애드온 12.3mb`) |
| 툴팁 | 애드온별 메모리 사용량(많은 순, 사용량에 따라 초록 → 빨강), 기본 UI 메모리, 전체 Lua 메모리 |
| Shift | 모든 애드온 표시 (기본은 30개, 나머지는 개수와 합계만) |
| 왼쪽 클릭 | Lua 메모리 정리 후 확보한 양을 채팅창에 출력 |

- 메모리 측정은 15초에 한 번만 하고, 전투 중에는 바를 갱신하지 않습니다. 메모리 측정은 비용이 큰 작업이라 Blizzard 애드온 목록과 같은 기준을 따릅니다.

### 시스템

| 구분 | 내용 |
|---|---|
| 바 | FPS와 지연 시간 (1초마다 갱신) |
| 툴팁 | 애드온 전체 CPU 사용률, 애드온별 CPU 사용률(높은 순), 지연 시간(지역/월드) |
| Shift | 모든 애드온 표시 (기본은 30개) |
| 왼쪽 클릭 | Blizzard 애드온 목록 창 열기/닫기 |

- FPS 색: 30 미만 빨강, 60 미만 노랑, 그 이상 초록
- 지연 시간 색: 100ms 미만 초록, 300ms까지 노랑, 그 이상 빨강
- CPU 사용률은 게임에 내장된 애드온 측정 기능(최근 60프레임 평균)을 읽어서 보여 줍니다. 계산 방식이 Blizzard 애드온 목록과 같아서 같은 수치가 나옵니다. 측정은 게임이 항상 하고 있으므로 diminfo가 추가로 부담을 주지 않습니다.

### 친구

| 구분 | 내용 |
|---|---|
| 바 | 접속 중인 친구 수 (게임 친구 + 배틀넷 친구) |
| 툴팁 | 게임 친구: 레벨, 이름(직업 색), 상태 아이콘, 지역(나와 같은 지역이면 초록) / 배틀넷 친구: 접속한 게임 아이콘, 캐릭터, 지역이나 게임 상태, 계정 이름 |
| Shift | 배틀넷 WoW 친구의 서버 표시 (나와 같은 서버면 초록) |
| 왼쪽 클릭 | 친구 창 |
| 오른쪽 클릭 | 메뉴: 초대, 귓속말, 내 상태 변경(대화 가능, 다른 용무 중, 자리 비움) |

- 접속 중인 친구가 없으면 툴팁이 뜨지 않습니다.
- 배틀넷 친구 초대는 같은 게임(Forever), 같은 지역, 같은 진영인 캐릭터만 목록에 나옵니다.

### 길드

| 구분 | 내용 |
|---|---|
| 바 | 게임에 접속 중인 길드원 수 (모바일 앱 접속 제외) |
| 툴팁 | 길드 이름, 접속/전체 인원, 내 등급, 길드 공지, 접속 중인 길드원 목록(최대 39명) |
| Shift | 이름과 등급, 길드원 메모, 관리자 메모 표시, 등급순 정렬 |
| 왼쪽 클릭 | 길드 및 커뮤니티 창 (J 키와 같음) |
| 오른쪽 클릭 | 메뉴: 초대(파티에 없는 길드원), 귓속말, 정렬 기준(이름/등급/레벨/지역/직업), 길드 창 열기 |

- 목록 표시: 레벨, 이름(직업 색), 파티원 표시(회색 `*`), 본인 표시(초록 `*`), 자리 비움/다른 용무 중 아이콘, 지역(나와 같은 지역이면 초록)
- 정렬 기준은 저장되어 다음 접속 때도 유지됩니다.
- 길드원의 접속, 가입, 탈퇴 이벤트가 오면 해당 길드원만 갱신합니다. 전체 명단 확인은 최소 30초 간격으로만 하고, 마우스를 올렸을 때는 바로 확인합니다(1초 쿨타임).
- 보스전 등 채팅 잠금 중에는 게임 규칙상 길드 정보를 읽을 수 없어서 툴팁이 뜨지 않습니다.
- 전투 중에는 오른쪽 클릭 메뉴가 열리지 않습니다.

### 소지금

| 구분 | 내용 |
|---|---|
| 바 | 소지금 (금, 은, 동 아이콘) |
| 툴팁 | 현재 소지금, 이번 접속의 수입과 지출, 이번 접속 순이익(수입 − 지출, 이익 초록 / 손실 빨강), 접속 시간 |
| 오른쪽 클릭 | 툴팁 화폐 표시 방식 바꾸기: 숨김 → 가방에 표시한 화폐 → 모든 화폐 |

- 수입과 지출은 접속하거나 `/reload` 하면 0부터 다시 셉니다.
- **화폐**: 툴팁 아래쪽에 화폐를 보여 줍니다. 오른쪽 클릭할 때마다 표시 방식이 바뀌고, 설정은 저장됩니다(기본: 가방에 표시한 화폐).
  - **가방에 표시한 화폐**: 캐릭터 창(C) → 화폐 탭에서 "가방에 표시"로 고른 화폐
  - **모든 화폐**: 가진 화폐 전부(보유량 0 제외, 분류 제목과 함께). 화폐 탭에서 접어 둔 분류 안의 화폐는 나오지 않습니다.

### 내구도

| 구분 | 내용 |
|---|---|
| 바 | 장비 평균 내구도 %. 색은 **가장 낮은 장비** 기준(빨강 → 노랑 → 초록). 가장 낮은 장비가 경고 기준(기본 30%) 미만이면 `내구도 91% (최저 5%)`처럼 최저값도 표시 |
| 툴팁 | 특성 트리별 투자 포인트(예: `31/0/20`), 장비 칸별 아이템과 내구도 %, 자동 수리 상태 |
| 왼쪽 클릭 | 캐릭터 창 |
| 오른쪽 클릭 | 자동 수리 켜기/끄기 |

- **자동 수리**: 상인 창을 열면 모든 장비를 수리하고 수리비를 채팅창에 출력합니다. 돈이 부족하면 안내 메시지만 출력합니다.
- 내구도가 없는 장비(투척 무기 등)는 개수를 보여 줍니다.
- 내구도가 바뀌거나 장비를 교체할 때 바로 갱신됩니다.

### 가방

| 구분 | 내용 |
|---|---|
| 바 | 빈 칸 / 전체 칸 (기본 가방 + 가방 4개) |
| 툴팁 | 빈 칸, 전체 칸, 사용 중인 칸, 자동 판매 상태 |
| 왼쪽 클릭 | 모든 가방 열기 |
| 오른쪽 클릭 | 회색 아이템 자동 판매 켜기/끄기 |

- **자동 판매**: 상인 창을 열면 회색(잡동사니) 아이템을 모두 팝니다. 상인 창의 "잡동사니 모두 팔기" 버튼과 같은 기능이라, 가방 설정에서 판매 제외로 지정한 가방은 팔지 않습니다. 판매 금액은 게임 메시지로 표시됩니다.

### 지역 (가운데)

| 구분 | 내용 |
|---|---|
| 바 | 현재 지역 이름(세부 지역이 있으면 세부 지역). PvP 상태에 따라 색이 바뀝니다 (아군 초록, 적군 빨강, 분쟁 주황, 성역 하늘색 등) |
| 툴팁 | 지역 이름과 좌표, 세부 지역, 지역 상태(아군 지역, 분쟁 지역 등) |
| 왼쪽 클릭 | 세계 지도 |
| 오른쪽 클릭 | 채팅 입력창에 `지역 (x, y)` 입력 |

- 툴팁을 띄워 둔 채 움직이면 좌표가 실시간으로 바뀝니다.
- 인스턴스 안에서는 좌표를 표시하지 않습니다.

### 시계 (기본 꺼짐)

| 구분 | 내용 |
|---|---|
| 바 | 현재 시각 (게임 시계 설정의 지역/서버 시간, 24시간제 설정을 따름) |
| 툴팁 | 지역 시간, 서버 시간, 귀속된 공격대와 초기화까지 남은 시간(연장된 귀속은 초록) |
| 왼쪽 클릭 | 채널 창 |
| 오른쪽 클릭 | 시계 창 |

- `Config.lua`에서 `C.Time`과 `C.TimePoint` 줄의 주석(`--`)을 지우면 켜집니다.

## 게임 안 설정 창

**ESC → 설정 → 애드온 → diminfo** 또는 채팅창에 `/diminfo`를 입력하면 열립니다. 값을 바꾸면 바로 반영되고, 계정 공통으로 저장됩니다.

| 구분 | 설정 |
|---|---|
| 표시 | 이름표 직업 색, 글자 크기, 툴팁에 보여 줄 애드온 수, 내구도 경고 기준(%) |
| 배경 패널 | 너비, 높이, 세로 위치 |
| 항목 위치 | 켜져 있는 항목별 가로 위치 |

- **기본값으로 되돌리기** 버튼을 누르면 모든 설정이 `Config.lua`의 값으로 돌아갑니다.
- 설정 창에서 바꾼 값만 저장됩니다. 바꾸지 않은 값은 `Config.lua`를 고치면 그대로 따라갑니다.
- 항목 켜기/끄기는 설정 창에 없고, `Config.lua`에서 바꿉니다.

## 설정 (`Config.lua`)

항목 켜기/끄기와 설정 창의 기본값은 `Config.lua`를 직접 고친 뒤 `/reload` 하면 적용됩니다.

| 설정 | 기본값 | 설명 |
|---|---|---|
| `C.Panel` | `true` | 배경 패널 표시 |
| `C.Panel1` | 너비 800, 높이 15, 화면 위 가운데 | 배경 패널 위치와 크기. `C.Panel2`~`C.Panel5`로 패널을 더 만들 수 있습니다 |
| `C.ClassColor` | `true` | 항목 이름표를 내 직업 색으로 표시 |
| `G.Fonts`, `G.FontSize`, `G.FontFlag` | 기본 글꼴, 12, 외곽선 | 글꼴, 글자 크기, 외곽선 |
| `C.MaxAddOns` | `30` | 메모리, CPU 툴팁에 기본으로 보여 줄 애드온 수 |
| `C.DurabilityWarn` | `30` | 가장 낮은 장비가 이 % 미만이면 바에 최저값 표시 |
| `C.<항목>` | `true` (시계만 꺼짐) | 각 항목 사용 여부 (`C.Memory`, `C.System`, `C.Friends`, `C.Guild`, `C.Money`, `C.Durability`, `C.Bags`, `C.Positions`, `C.Time`) |
| `C.<항목>Point` | | 각 항목의 위치 (예: `{"LEFT", "panel1", "LEFT", 17, 0}`) |

### 저장되는 값 (`SavedVariables: diminfo`)

| 값 | 기본값 | 바꾸는 방법 |
|---|---|---|
| `AutoSell` | 켜짐 | 가방 항목 오른쪽 클릭 |
| `AutoRepair` | 켜짐 | 내구도 항목 오른쪽 클릭 |
| `CurrencyMode` | 가방에 표시한 화폐 | 소지금 항목 오른쪽 클릭 |
| `Sort` | 직업순 | 길드 항목 오른쪽 클릭 → 정렬 |

## 변경 내역

### F1.0 (WoW Forever 이전)

- TBC 클래식(Interface 20505)에서 WoW Forever(Interface 16001) 전용으로 이전했습니다. TBC 지원은 중단했습니다.
- Forever에 없거나 제거 예정인 함수를 문서화된 최신 API로 바꿨습니다. (`C_Traits`, `C_Club`, `C_Item`, `C_CurrencyInfo`, `C_PvP`, `C_PartyInfo`, `C_BattleNet`, `C_AddOnProfiler`, `C_MerchantFrame` 등)
- CPU 측정을 게임 내장 측정 기능으로 바꿔 리로드 없이 항상 볼 수 있습니다.
- 자동 판매를 Blizzard "잡동사니 모두 팔기" 기능으로 바꿨습니다.
- 자동 메모리 정리 기능을 삭제했습니다(전투 후 끊김의 원인).
- 길드 초대 메뉴가 동작하지 않던 문제, 친구 툴팁 Shift 갱신 문제 등 기존 버그를 고쳤습니다.
- 메모리 측정 주기, 길드 명단 갱신, 좌표 툴팁 갱신 등 상시 부하를 줄였습니다.
